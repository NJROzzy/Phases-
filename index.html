02

Phase 02 · Robots that learn

Then I taught robots to learn by trial, and by watching.

Reinforcement learning in simulation

Built multi-task MuJoCo environments and benchmarked DDPG and A3C agents for continuous control: convergence, reward shaping, and policy robustness.

Python · MuJoCo · DDPG · A3C

Imitation learning for peg-in-hole

Implemented the Action Chunking Transformer (ACT) for contact-rich insertion, using 3-view RGB, joint states and end-effector pose. It outperformed RL baselines on sub-millimeter precision tasks.

Python · MuJoCo · PyTorch
