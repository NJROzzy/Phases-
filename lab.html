Interactive laboratory

Run a world. Watch it live its phases.

State a hypothesis, set the rules of an ecosystem of foraging agents, and run it. Every run moves through the six phases, is fully reproducible from its seed, and can be exported, compared and carried into the next cycle.

01 · Conception

Design an experiment

Start with the question. Write down what you expect to happen, then choose the parameters that put it to the test. The seed makes the run repeatable.

Demo mode. No laboratory API is connected, so this page replays a recorded run. To run your own experiments, start the API on your computer and connect to it:

pip install -e engine -e api
python -m phases_api
